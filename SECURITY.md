# Security

Only the latest release is maintained. Please report ordinary bugs through [issues](https://github.com/jjthibau/pf2e-item-spellcasting/issues). For vulnerabilities, use GitHub's private vulnerability reporting when enabled or contact the maintainer through their GitHub profile. Do not publish credentials, private worlds or exploit details in a public issue.

The module runs inside Foundry and shares its trust model. Actor updates validate the requesting user's ownership and use an active actor updater; it does not add network services or telemetry.
